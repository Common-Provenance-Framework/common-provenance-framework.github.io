# Common Provenance Model website

Static website of the Common Provenance Model (CPM), served at
<https://www.commonprovenancemodel.org>.

## Contents

- Site pages: `/`, `/about/`, `/specification/`, `/usage/`, `/ontologies/`
- Ontologies under `/ns/`, each with HTML documentation (`index.html`, generated by
  [Widoco](https://github.com/dgarijo/Widoco)) and four serializations:

| Ontology | IRI | Files |
|---|---|---|
| CPM-O | `https://www.commonprovenancemodel.org/ns/cpm#` | `ns/cpm/ontology.{ttl,owl,nt,jsonld}` |
| PBM-O | `https://www.commonprovenancemodel.org/ns/pbm#` | `ns/pbm/ontology.{ttl,owl,nt,jsonld}` |
| PDG-O | `https://www.commonprovenancemodel.org/ns/pdg#` | `ns/pdg/ontology.{ttl,owl,nt,jsonld}` |

## Viewing locally

```bash
python -m http.server 8000
```

Run it from the repository root, then open <http://localhost:8000/>. Opening the files
directly (`file://`) does not work, because the ontology pages load their sections with
JavaScript and site links start with `/`.
