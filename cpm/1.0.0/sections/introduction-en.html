Introduction back to ToC

The Common Provenance Model Ontology (CPM-O) is the OWL 2 representation of the terms of the Common Provenance Model (CPM). CPM is part of the Common Provenance Framework (CPF). CPF supports provenance of objects, physical or digital, that pass through several organisations. Each organisation documents its part of an object's history as a finalized provenance component, and connectors link the components into a provenance chain that can be followed across organisational boundaries.

The primary purpose of CPM-O is to provide persistent IRIs, labels and definitions for the CPM terms, so that they can be referenced from provenance documents in PROV-N, PROV-JSON, PROV-XML or RDF. CPM-O extends the W3C PROV Ontology (PROV-O), which it imports: every CPM class is a subclass of a PROV-O class.

CPM structures

CPM defines the following structures. Each is identified in PROV-N and PROV-JSON by a value of the prov:type attribute. In CPM-O each type value corresponds to a class (see Using CPM terms).

Classprov:type valueSubclass ofDefinition
cpm:MainActivitycpm:mainActivityprov:Activity a provenance structure that represents the described activity documented in a particular provenance component.
cpm:BackwardConnectorcpm:backwardConnectorprov:Entity a connector that represents a received described object.
cpm:ForwardConnectorcpm:forwardConnectorprov:Entity a connector that represents a described object that can be sent from a sender to a receiver.
cpm:ForwardConnectorSpecializedcpm:specForwardConnectorprov:Entity a connector that represents a described object that has been sent from a sender to a receiver.
cpm:IdentifierEntitycpm:idprov:Entity a provenance structure that represents an external identifier.
cpm:CurrentAgentcpm:currentAgentprov:Organization a provenance structure that represents a provenance controller.
cpm:SenderAgentcpm:senderAgentprov:Organization a provenance structure that represents a sender in the context of passing a described object between two provenance controllers.
cpm:ReceiverAgentcpm:receiverAgentprov:Organization a provenance structure that represents a receiver in the context of passing a described object between two provenance controllers.

The CPM attributes (e.g. cpm:referencedBundleId, cpm:hashAlg, cpm:contactIdPid) are defined as datatype properties. Their definitions are listed in the cross-reference section.

Using CPM terms

The following PROV-N example shows a backward connector and the sender agent to which it is attributed. All identifiers and values are illustrative.

document
  prefix ex <https://example.org/>
  prefix cpm <https://www.commonprovenancemodel.org/cpm#>

  entity(ex:bc1, [prov:type='cpm:backwardConnector',
                  cpm:referencedBundleId="https://example.org/bundles/b0" %% xsd:anyURI,
                  cpm:referencedMetaBundleId="https://example.org/meta/m0" %% xsd:anyURI,
                  cpm:referencedBundleSpecV="ISO-IS-23494-2:2026",
                  cpm:referencedMetaBundleSpecV="ISO-IS-23494-2:2026",
                  cpm:referencedBundleHashValue="9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08",
                  cpm:hashAlg="SHA256"])
  agent(ex:org1, [prov:type='cpm:senderAgent',
                  cpm:contactIdPid="https://example.org/contacts/org1" %% xsd:anyURI])
  wasAttributedTo(ex:bc1, ex:org1)
endDocument

Following PROV-O, the prov:type attribute is expressed in RDF with rdf:type. Standard PROV tools therefore produce the following RDF from the example above (excerpt):

ex:bc1 a prov:Entity, cpm:backwardConnector ;
    prov:wasAttributedTo ex:org1 ;
    cpm:referencedBundleId "https://example.org/bundles/b0"^^xsd:anyURI ;
    cpm:hashAlg "SHA256" .

ex:org1 a prov:Agent, cpm:senderAgent ;
    cpm:contactIdPid "https://example.org/contacts/org1"^^xsd:anyURI .

Please note:

  • Identifier values. The values of cpm:referencedBundleId, cpm:referencedMetaBundleId, cpm:provenanceServiceUri and cpm:contactIdPid are full IRIs given as literals of type xsd:anyURI, as in the example above. Untyped strings are inconsistent with CPM-O.

Scope of this version

In this version, CPM-O serves primarily as a vocabulary: it declares the CPM classes and attributes, provides their definitions and aligns them with PROV-O. Constraints for checking conformance to the CPM and further features are planned for future versions.

Known issues and feedback

Known defects of this version, related errata in ISO 23494-2 and their workarounds are listed on the known issues page. The development of the Common Provenance Framework takes place at https://github.com/Common-Provenance-Framework.
