Common Provenance Model Ontology (CPM-O): Description back to ToC

Each CPM type value (e.g. cpm:backwardConnector) is declared as a class equivalent to the corresponding CPM-O class (e.g. cpm:BackwardConnector), so RDF produced from PROV-N/PROV-JSON by standard PROV tooling is classified correctly. The implementations should use the capitalized class names.
