Common Provenance Model Ontology (CPM-O): Description back to ToC

Following PROV-O (Section 3.1), the PROV-DM attribute prov:type is expressed in RDF with rdf:type; CPM-O therefore does not declare prov:type. PROV-N, PROV-JSON and PROV-XML keep prov:type unchanged, e.g. prov:type='cpm:backwardConnector'. Each CPM type value (e.g. cpm:backwardConnector) is declared as a class equivalent to the corresponding CPM-O class (e.g. cpm:BackwardConnector), so RDF produced from PROV-N/PROV-JSON by standard PROV tooling is classified correctly. New RDF should use the capitalized class names.
