Abstract

The Provenance of Data Generation Ontology (PDG-O) expresses the Provenance of Data Generation (PDG) structures using the OWL 2 Web Ontology Language. The PDG structures are specializations of the provenance structures defined in W3C PROV-DM and are used together with the Common Provenance Model (CPM) to represent the provenance of data generation, such as the generated data, the data generation activities, and the devices, software, and other agents involved. PDG-O is an extension of PROV-O.
