Abstract

The Common Provenance Model Ontology (CPM-O) expresses the Common Provenance Model (CPM) using the OWL 2 Web Ontology Language (OWL 2). It provides a set of classes and properties that can be used to represent and interchange provenance information generated by different organizations in different systems and under different contexts. It can also be specialized to create new classes and properties to model provenance information for different applications and domains. CPM-O and CPM are part of the Common Provenance Framework (CPF). CPM-O is an extension of PROV-O. The CPM is standardized as ISO 23494-2 (Provenance information model for biological material and data — Part 2: Common provenance model).
